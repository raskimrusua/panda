# Image Attribution — Panda Marketing

All blog hero images in `marketing/public/blog/` are **AI-generated photorealistic
illustrations**, produced for Panda by Upstate Web Co.

- **Tool:** OpenAI GPT Image 2 (gpt-image-2), generated via the Atlas Cloud API
- **Pipeline:** `_personal/panda-crop-guides/run_hero_renders.py` (admin workspace)
- **Post-processing:** center-crop to 16:9, resized to 1600 × 900, saved as progressive JPEG (quality 82)
- **Depiction:** scenes are generic Kenyan smallholder farming imagery. **No real
  farms, no real people, and no real locations are depicted.** Any resemblance to an
  actual place or person is coincidental.
