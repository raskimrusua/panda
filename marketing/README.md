# Panda — marketing site

Astro 5 + Tailwind 4 + React islands. Deploys to Cloudflare Pages at
`panda.shira.farm`. Inherits Shira's brand theme (Highland Green, Savanna
Sun, DM Sans) with two Panda-specific accent colours added (`panda-leaf`,
`panda-dawn`).

## Local

```bash
npm install
npm run dev          # http://localhost:4321
```

## Build + deploy

```bash
# One-time: copy and fill the deploy creds
cp .env.example .env.deploy
# Paste CLOUDFLARE_API_TOKEN — same joshkim04 token Shira uses

# Each deploy
npm run deploy
```

The script sources `.env.deploy`, builds Astro, then `wrangler pages deploy`
the `dist/` folder to the `panda-marketing` CF Pages project.

| Path | Source | Notes |

Update copy by editing these files — no CMS yet. Keystatic + Markdoc are
deferred until Phase-8 when blog content needs editorial workflow.

## Theme

`src/styles/global.css` is the single source of truth. The `@theme` block
inherits Shira's full token set, then adds:

- `--color-panda-leaf: #74C69D;`
- `--color-panda-dawn: #FFF1E0;`

Both are used in `Navbar` (the `.` dot in the wordmark) and `Hero`
(the background of the eyebrow chip section). Everything else is Shira's
palette verbatim.
